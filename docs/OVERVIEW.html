🔍 Key Findings

  • Average Impact: Position changes average -0.023 (almost negligible)
  • High-Speed Tracks: Benefit most (+0.15 positions) due to ERS power increase
  • Street Circuits: Minimal impact (-0.02 positions) as weight matters less
  • Fair Regulations: Affect all teams equally, maintaining competitive balance
  • Lap Time Gains: Expected 2-3 seconds faster per lap overall
  • Strategic Shift: Reduced fuel flow requires more efficient race strategies

📊 Methodology

Data Source

FastF1 telemetry data covering 2022-2025 seasons (92 races total)

Machine Learning Model

XGBoost Regressor with 25 engineered features

Performance: MAE = 0.8 positions, R² = 0.85

Validation: 5-fold time-series cross-validation

Monte Carlo Simulation

2,000 iterations per race, varying:

  • Driver form (σ = 0.05)
  • Weather conditions (σ = 0.10)
  • Strategy choices (σ = 0.10)

Regulation Modeling

Five key multipliers applied to baseline features (power, aero, weight, fuel, tires)
